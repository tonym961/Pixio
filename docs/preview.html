Impostazioni

Share Windows, rete, opzioni avanzate, accesso.

Sorgenti ISO

Share Windows remote (sola lettura)
Anche una sottocartella: \\SRV-FILE\Software\ISO. Puoi aggiungerne più di una.
Salvata in /etc/pixio/smb.cred, leggibile solo da root.
Libreria locale su Pixio
Share Samba in scrittura \\10.10.0.254\iso
Per copiare ISO da Windows con Esplora file. Utente pixio, password impostata qui.
Upload dalla web UI
Trascina la ISO nella pagina Catalogo. Riprende da dove si era interrotto.
Scansione automatica
Cerca nuove ISO in tutte le sorgenti ogni 10 minuti.

Rete e boot

Installazione Windows via rete
Il setup di Windows deve leggere install.wim da un percorso SMB. Disattivato: nessuna condivisione locale.
Copia locale delle ISO grandi
Copia su disco le ISO oltre 2 GB per non dipendere dalla share durante il boot.

Cosa vedi al boot

Premi F12 (o il tasto di boot da rete del PC), la scheda di rete parla con Pixio e dopo pochi secondi appare questo menu. Testo puro, funziona uguale in BIOS e UEFI, tastiera per scegliere.

Dell OptiPlex 7010 · UEFI · d8:bb:c1:4a:20:7efrecce = scegli · Invio = avvia · Esc = disco locale
0–3 s
DHCP e proxy
Il DHCP aziendale dà l'IP, Pixio aggiunge solo "il boot file sta qui".
3–5 s
iPXE via TFTP
undionly.kpxe (BIOS) o ipxe.efi (UEFI), 100–1000 KB.
5–6 s
Menu via HTTP
Pixio genera il menu in base al firmware del PC.
poi
Kernel e file dalla ISO
Serviti via HTTP dalla ISO montata; le ISO Windows passano da wimboot.
Secure Boot. iPXE non è firmato Microsoft: sui PC con Secure Boot attivo va disattivato per il boot da rete (la GUI lo ricorda nella pagina Client quando rileva un tentativo fallito).
